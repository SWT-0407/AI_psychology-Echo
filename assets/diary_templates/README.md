Put the original diary template images in this folder with these exact names:

- `cover.jpg`
- `intro.jpg`
- `calendar.jpg`
- `history.jpg`
- `chat.jpg`

When these files exist, the Streamlit diary pages use them directly as page backgrounds. The original text, tab labels, drawings, and fonts inside the images are not redrawn or restyled by code.

The app overlays only dynamic data such as saved profile values, mood emoji, history snippets, and chat bubbles.
